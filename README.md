#  ![c (1)](https://github.com/user-attachments/assets/7e515e7e-9318-41f7-8a54-897f458f0979) Fit-mobileApp
> Aplicacion de rutina de ejercicio creada con Android studio y Java que permite agregar nuevas rutinas con ejercicios prehechos o usar la rutina de ejemplo
>
> idioma: Español
# 🏛 Arquitectura
Este proyecto de software se construyó utilizando una arquitectura MVC.

![image](https://github.com/user-attachments/assets/4f0e798d-1182-448b-8f79-01e85df774bb)

# 📦 Características
* Pantalla de bienvenida
* Visualización de rutinas existentes.
* Formulario para la creacion de nueva rutina
* Pantalla para inicio de rutina
* Actividad de cronómetro con lista de pasos para la rutina.

* Utilice Android studio y configura un nuevo dispositivo (El proyecto fue probado en Pixel 7 API 28), verifica que el archivo gradle este sincronizado y despliega el proyecto en el emulador.
